# Fase 4A, as trocas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Jogadores amigos propõem, aceitam, recusam, cancelam e contrapropõem trocas de 1–3 espécimes por lado, com histórico de donos, cerimônia no aceite e destaque no feed.

**Architecture:** Uma Action por regra em `app/Actions/Trades/`, com o aceite numa transação que trava troca e espécimes (`lockForUpdate`, por id). Expiração calculada pela coluna `expires_at` (scope `open()`), sem tarefa agendada. Front em Inertia + Vue (`trades/Index`, `trades/Create`), cartas de troca num componente só e cerimônia em WAAPI puro reaproveitando `Sfx` e o círculo branco do fim do pack.

**Tech Stack:** Laravel 12, Pest, Inertia v3 + Vue 3 `<script setup>`, Tailwind 4, Wayfinder (`@/routes/...`), WAAPI (`lib/motion.ts`).

**Spec:** `docs/superpowers/specs/2026-10-14-trocas-design.md`

## Global Constraints

- PHP com `declare(strict_types=1)`; Pint preset Laravel; PHPStan verde (`composer ci:check`).
- Controller sem lógica: FormRequest valida formato, Action aplica regra, método ≤ 20 linhas.
- Nenhum número mágico: limites em `config('game.trades.*')`.
- Nenhuma decisão no cliente: quem recebe o quê, validade, "Nova na Pokédex" vêm do servidor. O cliente só filtra o que já veio e anima.
- Vocabulário: `Specimen`/`Species`; nunca "card"/"pokemon"/"instance" no código PHP. (No front, o componente visual pode se chamar `TradeCard` como os já existentes `CollectionCard`.)
- Migrations sempre com `down()`.
- Mensagens ao jogador em português; erros de regra como `ValidationException` na chave `trade` (geral) ou do campo.
- Commits em português, imperativo, sem prefixo, com a linha `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Layout crítico em Tailwind; conferir a 412px; sprites com `FittedSprite`.
- Animações respeitam `prefers-reduced-motion` (o `animate()` de `lib/motion.ts` já cuida) e o mudo de `lib/soundPreference.ts`.
- Branch `trocas`.

## Review Focus

1. **Proposta pendente cujo espécime já foi trocado em outra** — ao tentar aceitar, a troca deve cair com motivo "um espécime foi trocado", não estourar 500 nem entregar espécime de terceiro. Teste em Task 3.
2. **Aceitar proposta vencida pela URL direta** (`POST /trocas/{id}/aceitar` depois de 72h) — deve dar erro amigável, sem mover nada. Teste em Task 3 e Task 5.
3. **Jogador que deixou de ser amigo com proposta pendente** — aceitar ainda funciona? Decisão: a amizade é exigida só ao propor; aceite não reconfere (a outra pessoa já se comprometeu). Teste em Task 3 pinando isso.
4. **Contraproposta inválida** (ex.: pede um espécime que o outro não tem mais) — a original continua pendente. Teste em Task 4.
5. **Proponente vê a cerimônia duas vezes** — depois do `MarkTradeSeen`, abrir `/trocas` de novo não toca a cena; reabrir por "Concluídas" (`?troca=id`) toca sem marcar nada. Teste em Task 6.

```php
 */
```

```php
class Trade extends Model
{
    // ... fromUser, toUser, items como estão ...

    /**
     * @return BelongsTo<Trade, $this>
     */
    public function counterOf(): BelongsTo
    {
        return $this->belongsTo(Trade::class, 'counter_of_id');
    }

    /**
     * Pendente e dentro da validade: a única que dá pra aceitar, recusar
     * ou contrapropor. "Expirada" não é status gravado, é esta conta.
     *
     * @param  Builder<Trade>  $query
     */
    public function scopeOpen(Builder $query): void
    {
        $query->where('status', TradeStatus::Pending)->where('expires_at', '>', now());
    }

    /**
     * @param  Builder<Trade>  $query
     */
    public function scopeInvolving(Builder $query, User $user): void
    {
        $query->where(fn (Builder $q) => $q->where('from_user_id', $user->id)->orWhere('to_user_id', $user->id));
    }

    public function isOpen(): bool
    {
        return $this->status === TradeStatus::Pending && $this->expires_at->isFuture();
    }

    /** @return 'open'|'expired'|'cancelled'|'accepted'|'declined' */
    public function state(): string
    {
        return match ($this->status) {
            TradeStatus::Pending => $this->isOpen() ? 'open' : 'expired',
            TradeStatus::Accepted => 'accepted',
            TradeStatus::Declined => 'declined',
            TradeStatus::Cancelled => 'cancelled',
        };
    }

    /**
     * @return array<string, string>
     */
    protected function casts(): array
    {
        return [
            'status' => TradeStatus::class,
            'cancel_reason' => TradeCancelReason::class,
            'expires_at' => 'datetime',
            'responded_at' => 'datetime',
```

```php
<?php

declare(strict_types=1);

namespace App\Actions\Trades;

use App\Enums\TradeItemSide;
use App\Enums\TradeStatus;
use App\Models\Specimen;
use App\Models\Trade;
use App\Models\TradeItem;
use App\Models\User;
use Illuminate\Support\Facades\DB;
use Illuminate\Validation\ValidationException;

/**
 * Proposta de troca entre amigos: de 1 a `max_items_per_side` espécimes de
 * cada lado, os oferecidos de quem propõe e os pedidos do amigo, todos
 * revelados. Vence em `expires_after_hours`. A contraproposta passa por
 * aqui também, com `$counterOf`.
 */
class ProposeTrade
{
    /**
     * @param  array<int, int>  $offeredIds
     * @param  array<int, int>  $requestedIds
     */
    public function handle(User $proposer, User $friend, array $offeredIds, array $requestedIds, ?string $message, ?Trade $counterOf = null): Trade
    {
        if ($proposer->is($friend) || ! in_array($friend->id, $proposer->friendIds(), true)) {
            $this->fail('trade', 'Só dá pra trocar com amigos.');
        }

        $offered = $this->side($offeredIds, 'offered');
        $requested = $this->side($requestedIds, 'requested');

        if (array_intersect($offered, $requested) !== []) {
            $this->fail('trade', 'Um espécime não pode entrar duas vezes.');
        }

        if (! $this->ownsAll($proposer, $offered)) {
            $this->fail('offered', 'Algum espécime oferecido não é seu.');
        }

        if (! $this->ownsAll($friend, $requested)) {
            $this->fail('requested', "Algum espécime pedido não é de {$friend->nickname}.");
        }

        $max = (int) config('game.trades.max_pending_outgoing');

        if (Trade::query()->open()->where('from_user_id', $proposer->id)->count() >= $max) {
            $this->fail('trade', "Você já tem {$max} propostas esperando resposta.");
        }

        if ($this->alreadyProposed($proposer, $friend, $offered, $requested)) {
            $this->fail('trade', 'Você já propôs essa troca.');
        }

        $message = trim((string) $message);

        return DB::transaction(function () use ($proposer, $friend, $offered, $requested, $message, $counterOf): Trade {
            $trade = Trade::create([
                'from_user_id' => $proposer->id,
                'to_user_id' => $friend->id,
                'counter_of_id' => $counterOf?->id,
                'status' => TradeStatus::Pending,
                'message' => $message === '' ? null : $message,
                'expires_at' => now()->addHours((int) config('game.trades.expires_after_hours')),
            ]);

            $trade->items()->createMany([
                ...array_map(fn (int $id): array => ['specimen_id' => $id, 'side' => TradeItemSide::Offered], $offered),
                ...array_map(fn (int $id): array => ['specimen_id' => $id, 'side' => TradeItemSide::Requested], $requested),
            ]);

            return $trade;
        });
    }

    /**
     * @param  array<int, int>  $ids
     * @return list<int>
     */
    private function side(array $ids, string $key): array
    {
        $ids = array_map('intval', array_values($ids));
        $max = (int) config('game.trades.max_items_per_side');

        if ($ids === [] || count($ids) > $max) {
            $this->fail($key, "Escolha de 1 a {$max} espécimes de cada lado.");
        }

        if (count(array_unique($ids)) !== count($ids)) {
            $this->fail('trade', 'Um espécime não pode entrar duas vezes.');
        }

        sort($ids);

        return $ids;
    }

    /** @param  list<int>  $ids */
    private function ownsAll(User $owner, array $ids): bool
    {
        // O RevealedScope global já deixa de fora bola fechada.
        return Specimen::query()->whereIn('id', $ids)->where('user_id', $owner->id)->count() === count($ids);
    }

    /**
     * @param  list<int>  $offered
     * @param  list<int>  $requested
     */
    private function alreadyProposed(User $proposer, User $friend, array $offered, array $requested): bool
    {
        return Trade::query()
            ->open()
            ->where('from_user_id', $proposer->id)
            ->where('to_user_id', $friend->id)
            ->with('items')
            ->get()
            ->contains(function (Trade $trade) use ($offered, $requested): bool {
                $ids = fn (TradeItemSide $side): array => $trade->items->where('side', $side)->pluck('specimen_id')->map(fn ($id): int => (int) $id)->sort()->values()->all();

                return $ids(TradeItemSide::Offered) === $offered && $ids(TradeItemSide::Requested) === $requested;
            });
    }

    private function fail(string $key, string $message): never
    {
        throw ValidationException::withMessages([$key => $message]);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Actions\Trades;

use App\Actions\Profile\ResetUnownedAvatar;
use App\Enums\TradeCancelReason;
use App\Enums\TradeItemSide;
use App\Enums\TradeStatus;
use App\Models\Specimen;
use App\Models\SpecimenTransfer;
use App\Models\Trade;
use App\Models\TradeItem;
use App\Models\User;
use Illuminate\Support\Facades\DB;
use Illuminate\Validation\ValidationException;

/**
 * Aceite: numa transação, trava a troca e os espécimes (por id, contra
 * deadlock), confere que cada um ainda é de quem era, passa a posse,
 * grava o histórico, derruba as outras propostas com esses espécimes e
 * acerta o avatar dos dois. Se algum espécime mudou de dono, a troca cai
 * com "não disponível" (fica gravado mesmo com o erro).
 */
class AcceptTrade
{
    public function __construct(private readonly ResetUnownedAvatar $resetAvatar) {}

    public function handle(Trade $trade, User $accepter): Trade
    {
        $result = DB::transaction(function () use ($trade, $accepter): Trade|string {
            $locked = Trade::query()->lockForUpdate()->findOrFail($trade->id);

            if ($locked->to_user_id !== $accepter->id || ! $locked->isOpen()) {
                return 'not_pending';
            }

            $items = $locked->items()->get();
            $specimens = Specimen::query()
                ->whereIn('id', $items->pluck('specimen_id'))
                ->orderBy('id')
                ->lockForUpdate()
                ->get()
                ->keyBy('id');

            foreach ($items as $item) {
                if ($specimens->get($item->specimen_id)?->user_id !== $this->giver($locked, $item)) {
                    $this->cancelUnavailable(Trade::query()->whereKey($locked->id));

                    return 'unavailable';
                }
            }

            foreach ($items as $item) {
                $from = $this->giver($locked, $item);
                $to = $from === $locked->from_user_id ? $locked->to_user_id : $locked->from_user_id;
                $specimens->get($item->specimen_id)?->forceFill(['user_id' => $to])->save();
                SpecimenTransfer::create([
                    'specimen_id' => $item->specimen_id,
                    'from_user_id' => $from,
                    'to_user_id' => $to,
                    'trade_id' => $locked->id,
                    'transferred_at' => now(),
                ]);
            }

            $this->cancelUnavailable(Trade::query()
                ->where('status', TradeStatus::Pending)
                ->whereKeyNot($locked->id)
                ->whereHas('items', fn ($query) => $query->whereIn('specimen_id', $items->pluck('specimen_id'))));

            $locked->update(['status' => TradeStatus::Accepted, 'responded_at' => now()]);
            $this->resetAvatar->handle(User::findOrFail($locked->from_user_id));
            $this->resetAvatar->handle(User::findOrFail($locked->to_user_id));

            return $locked;
        });

        return match ($result) {
            'not_pending' => throw ValidationException::withMessages(['trade' => 'Essa proposta não está mais pendente.']),
            'unavailable' => throw ValidationException::withMessages(['trade' => 'Algum espécime dessa troca não está mais disponível.']),
            default => $result,
        };
    }

    private function giver(Trade $trade, TradeItem $item): int
    {
        return $item->side === TradeItemSide::Offered ? $trade->from_user_id : $trade->to_user_id;
    }

    /** @param  \Illuminate\Database\Eloquent\Builder<Trade>  $query */
    private function cancelUnavailable($query): void
    {
        $query->update([
            'status' => TradeStatus::Cancelled,
            'cancel_reason' => TradeCancelReason::Unavailable,
            'responded_at' => now(),
        ]);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Actions\Trades;

use App\Enums\TradeItemSide;
use App\Enums\TradeStatus;
use App\Http\Resources\TradeSpecimenResource;
use App\Models\Specimen;
use App\Models\Trade;
use App\Models\TradeItem;
use App\Models\User;
use Illuminate\Http\Request;

/**
 * O que a cerimônia mostra pra quem vê: o que recebeu, o que deu e quais
 * espécies recebidas são novas na Pokédex dele (nenhum outro espécime da
 * espécie fora os recebidos nesta troca). `markSeen` diz se o front deve
 * avisar que o proponente viu.
 */
class BuildTradeCeremony
{
    /**
     * @return array{tradeId: int, other: array{id: int, nickname: string, avatarSpritePath: string|null}, received: list<array<string, mixed>>, given: list<array<string, mixed>>, newSpeciesIds: list<int>, markSeen: bool}|null
     */
    public function handle(Trade $trade, User $viewer, Request $request): ?array
    {
        if ($trade->status !== TradeStatus::Accepted || ! in_array($viewer->id, [$trade->from_user_id, $trade->to_user_id], true)) {
            return null;
        }

        $trade->loadMissing(['items.specimen.species', 'fromUser.avatarSpecies', 'toUser.avatarSpecies']);
        $isProposer = $trade->from_user_id === $viewer->id;
        $other = $isProposer ? $trade->toUser : $trade->fromUser;
        $receivedSide = $isProposer ? TradeItemSide::Requested : TradeItemSide::Offered;
        $received = $trade->items->where('side', $receivedSide)->map(fn (TradeItem $item): Specimen => $item->specimen);
        $given = $trade->items->where('side', '!=', $receivedSide)->map(fn (TradeItem $item): Specimen => $item->specimen);
        $card = fn (Specimen $specimen): array => (new TradeSpecimenResource($specimen))->toArray($request);

        $newSpeciesIds = $received
            ->pluck('species_id')
            ->unique()
            ->filter(fn (int $speciesId): bool => ! $viewer->specimens()
                ->where('species_id', $speciesId)
                ->whereNotIn('id', $received->pluck('id'))
                ->exists())
            ->sort()
            ->values()
            ->all();

        return [
            'tradeId' => $trade->id,
            'other' => ['id' => $other->id, 'nickname' => (string) $other->nickname, 'avatarSpritePath' => $other->avatarSpritePath()],
            'received' => $received->map($card)->values()->all(),
            'given' => $given->map($card)->values()->all(),
            'newSpeciesIds' => $newSpeciesIds,
            'markSeen' => $isProposer && $trade->proposer_seen_at === null,
        ];
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Actions\Trades;

use App\Enums\TradeItemSide;
use App\Enums\TradeStatus;
use App\Http\Resources\TradeSpecimenResource;
use App\Models\Trade;
use App\Models\TradeItem;

use Carbon\Carbon;
use Illuminate\Http\Request;

/**
 * A tela de trocas: recebidas abertas, enviadas (abertas e as encerradas
 * sem resposta: vencidas e canceladas) e concluídas (aceitas e recusadas),
 * as encerradas só por `closed_visible_days`. Cada carta vem do ponto de
 * vista de quem vê (`give` / `receive`). Também diz qual cerimônia tocar:
 * a pedida em `?troca=` ou a primeira aceita que o proponente não viu.
 */
class BuildTradeInbox
{
    public function __construct(private readonly BuildTradeCeremony $ceremony) {}

    /**
     * @return array<string, mixed>
     */
    public function handle(User $viewer, Request $request): array
    {
        $since = now()->subDays((int) config('game.trades.closed_visible_days'));
        $trades = Trade::query()
            ->involving($viewer)
            ->where(fn ($query) => $query->where('status', TradeStatus::Pending)->orWhere('responded_at', '>=', $since))
            ->with(['items.specimen.species', 'fromUser.avatarSpecies', 'toUser.avatarSpecies'])
            ->latest()
            ->latest('id')
            ->get()
            ->reject(fn (Trade $trade): bool => $trade->state() === 'expired' && $trade->expires_at->lt($since));

        $present = fn (Trade $trade): array => $this->present($trade, $viewer, $request);
        $tab = in_array($request->query('aba'), ['enviadas', 'concluidas'], true) ? (string) $request->query('aba') : 'recebidas';

        return [
            'tab' => $tab,
            'received' => $trades->filter(fn (Trade $t): bool => $t->to_user_id === $viewer->id && $t->state() === 'open')->map($present)->values()->all(),
            'sent' => $trades->filter(fn (Trade $t): bool => $t->from_user_id === $viewer->id && in_array($t->state(), ['open', 'expired', 'cancelled'], true))->map($present)->values()->all(),
            'done' => $trades->filter(fn (Trade $t): bool => in_array($t->state(), ['accepted', 'declined'], true))->map($present)->values()->all(),
            'friends' => User::query()->whereIn('id', $viewer->friendIds())->with('avatarSpecies')->orderBy('nickname')->get()
                ->map(fn (User $friend): array => ['id' => $friend->id, 'nickname' => (string) $friend->nickname, 'avatarSpritePath' => $friend->avatarSpritePath()])
                ->all(),
            'ceremony' => $this->ceremonyFor($viewer, $request),
            'presencePollSeconds' => (int) config('game.group.presence_poll_seconds'),
        ];
    }

    /**
     * @return array<string, mixed>|null
     */
    private function ceremonyFor(User $viewer, Request $request): ?array
    {
        $trade = $request->filled('troca')
            ? Trade::query()->find($request->integer('troca'))
            : Trade::query()->where('from_user_id', $viewer->id)->where('status', TradeStatus::Accepted)->whereNull('proposer_seen_at')->oldest('responded_at')->first();

        $ceremony = $trade === null ? null : $this->ceremony->handle($trade, $viewer, $request);

        // Reaberta por "Concluídas": toca sem marcar nada.
        if ($ceremony !== null && $request->filled('troca')) {
            $ceremony['markSeen'] = false;
        }

        return $ceremony;
    }

    /**
     * @return array<string, mixed>
     */
    private function present(Trade $trade, User $viewer, Request $request): array
    {
        $isProposer = $trade->from_user_id === $viewer->id;
        $other = $isProposer ? $trade->toUser : $trade->fromUser;
        $side = fn (TradeItemSide $side): array => $trade->items->where('side', $side)
            ->map(fn (TradeItem $item): array => (new TradeSpecimenResource($item->specimen))->toArray($request))
            ->values()
            ->all();

        return [
            'id' => $trade->id,
            'direction' => $isProposer ? 'sent' : 'received',
            'state' => $trade->state(),
            'cancelReason' => $trade->cancel_reason?->value,
            'other' => ['id' => $other->id, 'nickname' => (string) $other->nickname, 'avatarSpritePath' => $other->avatarSpritePath()],
            'message' => $trade->message,
            'isCounter' => $trade->counter_of_id !== null,
            'expiresAt' => $trade->expires_at->toIso8601String(),
            'createdAgo' => $trade->created_at->diffForHumans(['locale' => 'pt_BR', 'options' => Carbon::JUST_NOW]),
            'give' => $side($isProposer ? TradeItemSide::Offered : TradeItemSide::Requested),
            'receive' => $side($isProposer ? TradeItemSide::Requested : TradeItemSide::Offered),
        ];
    }
}
```

```vue
import { computed, onBeforeUnmount, onMounted, ref } from 'vue';

/**
 * Validade da proposta: "vence em 2d 14h" com a barra esvaziando; nas
 * últimas 24h vira hh:mm:ss em vermelho. Só conta o `expiresAt` que veio
 * do servidor.

onBeforeUnmount(() => clearInterval(clock));

const remaining = computed(() => Math.max(0, new Date(props.expiresAt).getTime() - now.value));
const urgent = computed(() => remaining.value < 24 * 3600 * 1000);
const fraction = computed(() => Math.min(1, remaining.value / (props.totalHours * 3600 * 1000)));
const label = computed(() => {
    const seconds = Math.floor(remaining.value / 1000);
    const days = Math.floor(seconds / 86400);
    const hours = Math.floor((seconds % 86400) / 3600);
    const minutes = Math.floor((seconds % 3600) / 60);
    const pad = (n: number) => String(n).padStart(2, '0');

    if (remaining.value === 0) {
        return 'venceu';
    }

    return urgent.value
        ? `vence em ${pad(hours)}:${pad(minutes)}:${pad(seconds % 60)}`
        : `vence em ${days}d ${hours}h`;
});
</script>
```

```php
<?php

declare(strict_types=1);

namespace App\Actions\Trades;

use App\Enums\TradeItemSide;
use App\Http\Resources\TradeSpecimenResource;
use App\Models\Specimen;
use App\Models\Trade;
use App\Models\User;
use Illuminate\Http\Request;

/**
 * O montador: os espécimes de quem vê e do amigo (um por um, com mint e
 * IV), cada um marcado se o dono tem repetido da espécie, e o que já vem
 * na mesa (o `?pedir=` ou a contraproposta invertida). Os filtros do
 * front só escondem o que já veio daqui.
 *
 * @phpstan-type BuilderCard array{specimenId: int, speciesId: int, name: string, rarityTier: string, isShiny: bool, spritePath: string, mintNumber: int, ivTotal: int, duplicate: bool}
 */
class BuildTradeBuilder
{
    /**
     * @return array<string, mixed>
     */
    public function handle(User $viewer, User $friend, Request $request, ?Trade $counterOf = null): array
    {
        $mine = $this->collection($viewer, $request);
        $theirs = $this->collection($friend, $request);
        $theirIds = array_column($theirs, 'specimenId');

        $initial = ['give' => [], 'receive' => []];

        if ($counterOf !== null) {
            $counterOf->loadMissing('items');
            $initial = [
                'give' => $counterOf->items->where('side', TradeItemSide::Requested)->pluck('specimen_id')->map(fn ($id): int => (int) $id)->values()->all(),
                'receive' => $counterOf->items->where('side', TradeItemSide::Offered)->pluck('specimen_id')->map(fn ($id): int => (int) $id)->values()->all(),
            ];
        } elseif (in_array($request->integer('pedir'), $theirIds, true)) {
            $initial['receive'] = [$request->integer('pedir')];
        }

        return [
            'friend' => ['id' => $friend->id, 'nickname' => (string) $friend->nickname, 'tag' => (string) $friend->tag, 'avatarSpritePath' => $friend->avatarSpritePath()],
            'mine' => $mine,
            'theirs' => $theirs,
            'initial' => $initial,
            'counterOf' => $counterOf?->id,
            'limits' => [
                'perSide' => (int) config('game.trades.max_items_per_side'),
                'message' => (int) config('game.trades.message_max_length'),
            ],
        ];
    }

    /**
     * Em ordem de dex; dentro da espécie, shiny e IV maior primeiro.
     *
     * @return list<array<string, mixed>>
     */
    private function collection(User $owner, Request $request): array
    {
        $specimens = $owner->specimens()
            ->with('species')
            ->orderBy('species_id')
            ->orderByDesc('is_shiny')
            ->orderByDesc('iv_total')
            ->get();
        $perSpecies = $specimens->countBy('species_id');

        return array_values($specimens->map(fn (Specimen $specimen): array => [
            ...(new TradeSpecimenResource($specimen))->toArray($request),
            'duplicate' => $perSpecies[$specimen->species_id] > 1,
        ])->all());
    }
}
```

```ts
import { animate, finished, wait } from '@/lib/motion';
import type { Sfx } from '@/lib/pack/sfx';
import type { Tier } from '@/lib/pack/types';

/**
 * Roteiro da cerimônia (WAAPI puro, como o pack): as cartas dadas sobem
 * e as recebidas descem cruzando em arco com giro, flash no meio, as
 * recebidas brilham e o círculo branco cresce revelando o resumo. Com
 * movimento reduzido o `animate()` já encurta tudo.
 */
export async function playTradeCeremony(
    root: HTMLElement,
    sfx: Sfx | null,
    best: { tier: Tier; shiny: boolean },
): Promise<void> {
    const $ = (k: string) => root.querySelector<HTMLElement>(`[data-k="${k}"]`);
    const all = (k: string) => [...root.querySelectorAll<HTMLElement>(`[data-k="${k}"]`)];

    all('given').forEach((card, i) =>
        animate(card, [{ transform: 'scale(.6)', opacity: 0 }, { transform: 'none', opacity: 1 }], 420, {
            delay: i * 70,
            easing: 'cubic-bezier(.2,1.4,.4,1)',
        }),
    );
    all('received').forEach((card, i) =>
        animate(card, [{ transform: 'scale(.6)', opacity: 0 }, { transform: 'none', opacity: 1 }], 420, {
            delay: 120 + i * 70,
            easing: 'cubic-bezier(.2,1.4,.4,1)',
        }),
    );
    await wait(700);

    sfx?.whoosh(true);
    const travel = root.clientHeight * 0.32;
    const moves = [
        ...all('given').map((card) =>
            animate(card, [
                { transform: 'none' },
                { transform: `translate(${travel * 0.25}px, ${-travel / 2}px) rotateY(90deg) scale(1.08)`, offset: 0.5 },
                { transform: `translateY(${-travel}px) rotateY(180deg)` },
            ], 760, { easing: 'cubic-bezier(.6,0,.3,1)', fill: 'forwards' }),
        ),
        ...all('received').map((card) =>
            animate(card, [
                { transform: 'none' },
                { transform: `translate(${-travel * 0.25}px, ${travel / 2}px) rotateY(90deg) scale(1.08)`, offset: 0.5 },
                { transform: `translateY(${travel}px) rotateY(180deg)` },
            ], 760, { easing: 'cubic-bezier(.6,0,.3,1)', fill: 'forwards' }),
        ),
    ];
    await wait(380);
    sfx?.burst();
    animate($('flash'), [{ opacity: 0, transform: 'scale(.4)' }, { opacity: 1, transform: 'scale(1.6)', offset: 0.3 }, { opacity: 0, transform: 'scale(2.2)' }], 520);
    await Promise.all(moves.map(finished));
```
