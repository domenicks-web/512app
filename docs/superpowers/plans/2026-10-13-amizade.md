# Amizade de verdade — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar o "amigos = todo mundo do grupo" por amizade de verdade: pedido por `nickname#tag`, aceitar/recusar/cancelar/desfazer, amizade automática com quem convidou, contador no dock e "amigos online" só entre amigos.

**Architecture:** Uma tabela `friendships` (linha `pending` = pedido, `accepted` = amizade). Regras em Actions (`app/Actions/Friends/`), autorização numa `FriendshipPolicy` aplicada na rota com `->can()`, controllers invocáveis finos. A tela Amigos é reescrita; Home e tela Amigos fazem `usePoll` pra presença.

**Tech Stack:** Laravel (PHP 8.4, strict types), Pest, Inertia v3 + Vue 3 `<script setup>`, Tailwind v4, Wayfinder.

**Spec:** `docs/superpowers/specs/2026-10-13-amizade-design.md`

## Global Constraints

- `declare(strict_types=1)` em todo PHP; Pint (`vendor/bin/pint --dirty --format agent`) antes de commitar.
- Migrations sempre com `down()`. Enum nativo do PHP pra status.
- Nenhum número mágico: `game.group.online_window_minutes = 2`, `game.group.presence_poll_seconds = 60` em `config/game.php`.
- Controllers sem lógica: FormRequest → Action → `back()`. Erros de regra saem como `ValidationException` no campo `handle`.
- Vocabulário: não usar "card", "pokemon" solto nem "instance".
- Front: `<script setup lang="ts">`, Wayfinder (`@/routes/...`), `<Form :action="rota()">` (nunca `v-bind`), sem caixa de diálogo do navegador.
- Lint do front só em `resources/js`: `npx vp fmt resources/js` e `npx vp lint resources/js` (nunca `vp check --fix` sem caminho — reformata docs e quebra no handoff).
- Commits em português, imperativo, sem prefixo.
- Ranking e feed continuam com o grupo inteiro; só a tela Amigos e o "amigos online" usam amizade.

```php
<?php

declare(strict_types=1);

namespace App\Models;

use App\Enums\FriendshipStatus;
use Database\Factories\FriendshipFactory;
use Illuminate\Database\Eloquent\Attributes\Fillable;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Support\Carbon;

/**
 * Pedido de amizade (`pending`) ou amizade (`accepted`) entre dois
 * jogadores. O par é único nas duas direções — garantido pelas Actions de
 * `app/Actions/Friends/`. Recusar, cancelar e desfazer apagam a linha.
 *
 * @property int $id
 * @property int $requester_id
 * @property int $addressee_id
 * @property FriendshipStatus $status
 * @property Carbon|null $accepted_at
 * @property Carbon|null $created_at
 */
#[Fillable(['requester_id', 'addressee_id', 'status', 'accepted_at'])]
class Friendship extends Model
{
    /** @use HasFactory<FriendshipFactory> */
    use HasFactory;

    /**
     * @return BelongsTo<User, $this>
     */
    public function requester(): BelongsTo
    {
        return $this->belongsTo(User::class, 'requester_id');
    }

    /**
     * @return BelongsTo<User, $this>
     */
    public function addressee(): BelongsTo
    {
        return $this->belongsTo(User::class, 'addressee_id');
    }

    /** O outro lado da amizade, visto por `$user`. */
    public function otherThan(User $user): User
    {
        return $this->requester_id === $user->id ? $this->addressee : $this->requester;
    }

    /**
     * @param  Builder<self>  $query
     */
    public function scopeInvolving(Builder $query, User $user): void
    {
        $query->where(fn (Builder $q) => $q->where('requester_id', $user->id)->orWhere('addressee_id', $user->id));
    }

    /**
     * @param  Builder<self>  $query
     */
    public function scopeBetween(Builder $query, User $a, User $b): void
    {
        $query->where(fn (Builder $q) => $q
            ->where(fn (Builder $pair) => $pair->where('requester_id', $a->id)->where('addressee_id', $b->id))
            ->orWhere(fn (Builder $pair) => $pair->where('requester_id', $b->id)->where('addressee_id', $a->id)));
    }

    /**
     * @param  Builder<self>  $query
     */
    public function scopeAccepted(Builder $query): void
    {
        $query->where('status', FriendshipStatus::Accepted);
    }

    /**
     * @param  Builder<self>  $query
     */
    public function scopePending(Builder $query): void
    {
        $query->where('status', FriendshipStatus::Pending);
    }

    /**
     * @return array<string, string>
     */
    protected function casts(): array
    {
        return [
            'status' => FriendshipStatus::class,
            'accepted_at' => 'datetime',
        ];
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Actions\Friends;

use App\Enums\FriendshipStatus;
use App\Models\Friendship;
use App\Models\User;
use Illuminate\Support\Facades\DB;
use Illuminate\Validation\ValidationException;

/**
 * Pedido de amizade pelo `nickname#tag` completo (o nickname sem
 * diferenciar maiúscula). Se a outra pessoa já tinha mandado pedido, aceita
 * o dela em vez de criar outro. As duas linhas de `users` ficam travadas
 * na transação pra dois pedidos cruzados simultâneos não virarem duas
 * linhas.
 */
class SendFriendRequest
{
    public function __construct(private readonly AcceptFriendRequest $accept) {}

    public function handle(User $sender, string $handle): Friendship
    {
        $target = $this->findTarget($handle);

        if ($target->id === $sender->id) {
            $this->fail('Esse é você');
        }

        return DB::transaction(function () use ($sender, $target): Friendship {
            User::query()->whereKey([$sender->id, $target->id])->orderBy('id')->lockForUpdate()->get();

            $existing = Friendship::query()->between($sender, $target)->first();

            if ($existing?->status === FriendshipStatus::Accepted) {
                $this->fail('Vocês já são amigos');
            }

            if ($existing !== null && $existing->requester_id === $sender->id) {
                $this->fail('Você já mandou um pedido pra essa pessoa');
            }

            if ($existing !== null) {
                return $this->accept->handle($existing);
            }

            return Friendship::create([
                'requester_id' => $sender->id,
                'addressee_id' => $target->id,
                'status' => FriendshipStatus::Pending,
            ]);
        });
    }

    private function findTarget(string $handle): User
    {
        $handle = trim($handle);
        $separator = strrpos($handle, '#');
        $nickname = $separator === false ? '' : substr($handle, 0, $separator);
        $tag = $separator === false ? '' : substr($handle, $separator + 1);

        if ($nickname === '' || $tag === '') {
            $this->fail('Use o formato nickname#1234');
        }

        return User::query()
            ->whereRaw('lower(nickname) = ?', [mb_strtolower($nickname)])
            ->where('tag', $tag)
            ->first()
            ?? $this->fail('Não achei ninguém com esse nickname#tag');
    }

    private function fail(string $message): never
    {
        throw ValidationException::withMessages(['handle' => $message]);
    }
}
```

`app/Actions/Friends/BefriendInviter.php`:

```php
<?php

declare(strict_types=1);

namespace App\Actions\Friends;

use App\Enums\FriendshipStatus;
use App\Models\Friendship;
use App\Models\User;

/**
 * Quem criou o convite vira amigo de quem acabou de entrar. Se já existe
 * linha entre os dois, um pedido pendente é aceito; nada é duplicado.
 */
class BefriendInviter
{
    public function __construct(private readonly AcceptFriendRequest $accept = new AcceptFriendRequest) {}

    public function handle(User $user): void
    {
        $inviter = $user->invitedBy?->creator;

        if ($inviter === null || $inviter->id === $user->id) {
            return;
        }

        $existing = Friendship::query()->between($user, $inviter)->first();

        if ($existing?->status === FriendshipStatus::Pending) {
            $this->accept->handle($existing);
        }

        if ($existing !== null) {
            return;
        }

        Friendship::create([
            'requester_id' => $inviter->id,
            'addressee_id' => $user->id,
            'status' => FriendshipStatus::Accepted,
            'accepted_at' => now(),
        ]);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Policies;

use App\Enums\FriendshipStatus;
use App\Models\Friendship;
use App\Models\User;

class FriendshipPolicy
{
    /** Só quem recebeu aceita, e só enquanto é pedido. */
    public function accept(User $user, Friendship $friendship): bool
    {
        return $friendship->addressee_id === $user->id
            && $friendship->status === FriendshipStatus::Pending;
    }

    /** Recusar, cancelar ou desfazer: qualquer um dos dois lados. */
    public function delete(User $user, Friendship $friendship): bool
    {
        return in_array($user->id, [$friendship->requester_id, $friendship->addressee_id], true);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Actions\Friends;

use App\Enums\FriendshipStatus;
use App\Models\Friendship;
use App\Models\Specimen;
use App\Models\User;
use App\Services\GroupPresence;
use Carbon\CarbonInterface;

/**
 * A tela Amigos: amigos (online primeiro, depois por nickname) com
 * quantas espécies cada um tem, e os pedidos pendentes recebidos e
 * enviados.
 */
class BuildFriendList
{
    public function __construct(private readonly GroupPresence $presence) {}

    /**
     * @return array{
     *     friends: list<array{friendshipId: int, userId: int, nickname: string, tag: string, avatarSpritePath: string|null, ownedSpecies: int, isOnline: bool}>,
     *     incoming: list<array{friendshipId: int, nickname: string, tag: string, avatarSpritePath: string|null, sentAgo: string}>,
     *     outgoing: list<array{friendshipId: int, nickname: string, tag: string, avatarSpritePath: string|null, sentAgo: string}>,
     * }
     */
    public function handle(User $viewer, CarbonInterface $now): array
    {
        $friendships = Friendship::query()
            ->involving($viewer)
            ->with(['requester.avatarSpecies:id,sprite_path', 'addressee.avatarSpecies:id,sprite_path'])
            ->latest()
            ->latest('id')
            ->get();

        [$accepted, $pending] = $friendships->partition(fn (Friendship $friendship): bool => $friendship->status === FriendshipStatus::Accepted);
        $online = $this->presence->onlineUserIds($now);
        $ownedSpecies = Specimen::query()
            ->whereIn('user_id', $accepted->map(fn (Friendship $friendship): int => $friendship->otherThan($viewer)->id))
            ->selectRaw('user_id, count(distinct species_id) as owned_species')
            ->groupBy('user_id')
            ->pluck('owned_species', 'user_id');

        $friends = $accepted
            ->map(function (Friendship $friendship) use ($viewer, $online, $ownedSpecies): array {
                $friend = $friendship->otherThan($viewer);

                return [
                    'friendshipId' => $friendship->id,
                    'userId' => $friend->id,
                    'nickname' => (string) $friend->nickname,
                    'tag' => (string) $friend->tag,
                    'avatarSpritePath' => $friend->avatarSpecies?->sprite_path,
                    'ownedSpecies' => (int) ($ownedSpecies[$friend->id] ?? 0),
                    'isOnline' => in_array($friend->id, $online, true),
                ];
            })
            ->sort(fn (array $a, array $b): int => [$b['isOnline'], mb_strtolower($a['nickname'])]
                <=> [$a['isOnline'], mb_strtolower($b['nickname'])])
            ->values()
            ->all();

        $present = fn (Friendship $friendship): array => [
            'friendshipId' => $friendship->id,
            'nickname' => (string) $friendship->otherThan($viewer)->nickname,
            'tag' => (string) $friendship->otherThan($viewer)->tag,
            'avatarSpritePath' => $friendship->otherThan($viewer)->avatarSpecies?->sprite_path,
            'sentAgo' => $friendship->created_at?->locale('pt_BR')->diffForHumans() ?? '',
        ];

        return [
            'friends' => $friends,
            'incoming' => $pending->where('addressee_id', $viewer->id)->map($present)->values()->all(),
            'outgoing' => $pending->where('requester_id', $viewer->id)->map($present)->values()->all(),
        ];
    }
}
```
